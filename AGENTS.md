# Gobernanza de agentes para KardexBar

Antes de analizar, planificar o modificar el proyecto:

1. Lee y sigue íntegramente [`.agents/rules/AI_PROTOCOL.md`](.agents/rules/AI_PROTOCOL.md).
2. Lee [`.agents/rules/rules.md`](.agents/rules/rules.md) para aplicar la arquitectura y convenciones del repositorio.
3. Opera siempre bajo [`.agents/roles/orchestrator-agent.md`](.agents/roles/orchestrator-agent.md). No asumas un rol especialista ni cierres una tarea sin la transferencia obligatoria a QA descrita allí.

Las reglas de seguridad e integridad de datos tienen prioridad sobre la rapidez o la finalización de una tarea. No inventes contratos ni afirmes verificaciones que no ejecutaste.
